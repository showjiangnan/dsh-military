# ADR-0014：外部战术提炼采用来源快照、用户审阅与标签稳定 ID

- 状态：Accepted
- 日期：2026-08-18

## 背景

用户希望从历史会话和长期经验提炼私有战术。直接自动写入 Skill 会传播猜测、Secret、Prompt Injection、重复知识和不可追溯修改。

## 决策

来源先形成不可变快照和授权记录；系统产生 `TacticalExtractionCandidate`，区分新战术与现有战术补充。候选必须经过安全检查、来源覆盖验证和用户 Diff 审阅，才能形成新的 DRAFT 版本。标签使用稳定 `tagId`，暂停和删除不破坏历史引用，重命名只改显示名并保留 alias。

## 后果

- 提炼速度低于全自动写入，但可追溯、可回滚；
- 任意会话可作为显式来源，但不会因此启用 Military；
- 已发布战术版本不可就地改写；
- 标签删除采用 tombstone，需要维护历史读取逻辑。
