# 头脑风暴与用户决策检查清单

- [ ] 命令协议 id 为 `/brainstorm`，Web 显示“头脑风暴”。
- [ ] 命令只在 Military 根会话注册。
- [ ] 同一会话最多一个 ACTIVE Brainstorm Order。
- [ ] 每轮问题不超过配置上限，并提供停止/推荐选项。
- [ ] 可通过项目读取发现的事实不询问用户。
- [ ] Advisor/Chief 只产出 DecisionQuestionSet。
- [ ] General 是 `ask_user_question` 的唯一 Agent 所有者。
- [ ] 回答绑定 Question id 和 Brainstorm revision。
- [ ] 高风险授权不从普通偏好回答中推断。
- [ ] 空项目的 specs 由 Engineer 写入并本地 main commit。
- [ ] 取消/刷新后 pending question 可恢复或正确关闭。
- [ ] 最终 Mission Intent 明确已知、假设和未决项。
