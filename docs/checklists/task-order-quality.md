# Task Order 质量检查表

- [ ] 只有一个主要结果和主要动词。
- [ ] 与 Direction 的价值关系明确。
- [ ] Task Type 可路由到合适参谋、模型和 Verifier。
- [ ] 独立关键决策通常不超过三个。
- [ ] 写集合是有限且可加锁的。
- [ ] 不依赖其他 Agent 的未验收私有结论。
- [ ] Context Packet 没有携带整个 Mission 原始历史。
- [ ] Stop/Blocker/Escalation 条件清楚。
- [ ] Acceptance Contract 能独立接受或拒绝。
- [ ] 禁止副作用已列出。
- [ ] 预算与任务复杂度匹配。
- [ ] 拆分后的协调成本没有超过实际工作。
